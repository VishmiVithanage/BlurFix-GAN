Research Project: Efficient Image Blind Motion Deblurring Using Generative Adversarial Network

This research project proposes a GAN model, a deep learning-based framework for restoring sharpness in blurred images, improving visual clarity and the accuracy of downstream image analysis. The model learns to recover fine details such as edges and textures from motion blur, and is evaluated using standard quality metrics including PSNR and SSIM. A lightweight, easy-to-use interface allows users to upload a blurred image and obtain the restored result, supporting practical applications.
